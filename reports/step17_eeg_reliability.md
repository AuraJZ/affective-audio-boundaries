## 0. 结论

**同一批受试、同一批试次、同一套算法：**

| | 最强量 | ICC | 分半 SB |
|---|---|---|---|
| **主观评分**（8 项） | tender | **+0.335** | **+0.869** |
| **脑电**（156 维） | coh_OT_beta | **+0.092** | +0.511 |

156 个脑电特征**无一通过 BH-FDR<0.05**（最小 q=0.156），
且最强的脑电量 **仍低于最弱的主观量表**（energetic 0.158）。

> ⚠️ 本报告初版只用了 26 维带功率，最强 ICC 为 0.040，落差写作 8.3 倍。
> 补上相干与不对称后最强 ICC 升至 0.092，**落差实为 3.6 倍**。
> 只用带功率会**低估脑电侧**，见 §1b。

> **12 秒音乐片段引起的试次级脑电带功率变化，几乎不含跨受试可复现的
> 「刺激特异」成分；而同一批人对同一批片段的主观评分含有大量该成分。**

**这一次的阴性是可解读的** —— 因为流水线已被四项阳性对照验证，
不再存在 BIRAFFE2 那种「测不到还是测不准」的歧义。

## 1b. 补上文献用的特征类型 —— 否则是循环论证 ⭐

Daly et al. (2014) 用**同一批数据**报告的效应在**通道间相干**与
**beta/gamma 不对称**。本报告初版的 26 维只有区域带功率。
**用一个不含目标效应的特征集去否定该效应，是循环论证。**

`46_connectivity_features.py` 补了 130 维（相干 50 + 虚部相干 50 + 不对称 30），
`48_eeg_reliability_full.py` 用 156 维重算：

| 特征族 | n | 最强 ICC | 分半 SB |
|---|---|---|---|
| **相干** | 50 | **+0.092**（coh_OT_beta） | **+0.511** |
| 不对称 | 30 | +0.070（asym_T4T3_delta） | −0.268 |
| 虚部相干 | 50 | +0.043（icoh_FO_alpha） | +0.206 |
| 带功率 | 26 | +0.040（beta_central） | +0.173 |

**相干确实是最强的族，是带功率的两倍多** —— 与 Daly et al. 的定位一致。
这一步是必要的：不做就会低估脑电侧一倍以上。

但补齐之后：

- 156 次检验下**无一通过 FDR<0.05**（最小 q=0.156）
- 最强脑电量 0.092 **仍低于最弱的主观量表** 0.158

**结论方向不变，量级需修正。**

（虚部相干远低于普通相干，符合预期：普通相干含容积传导带来的零时延伪相关，
虚部相干把它剔掉。这也说明相干那 0.092 里有一部分不是真正的神经耦合。）

## 1. 一个必须讲清楚的区分 ⚠️

「刺激层面信度 ≈ 0」**不**等于「脑电对声音无响应」。

| | 结果 |
|---|---|
| 脑电对**声音起始**有响应吗 | ✅ **有**，452 ms，p=0.0001（`step16`） |
| 脑电能区分**不同片段**吗 | ❌ 跨受试一致的差异成分 ≈ 0 |

**共同成分很强，差异成分几乎没有。**
所有音乐都让大脑「动」，但不同音乐让不同的人「以相同方式动得不同」——
这一层不存在。

对产品的含义与 `step13` 撤回前的表述**在数字上相近、在依据上完全不同**：
那一次是流水线未验证，这一次是流水线已验证。

## 3. 两个数据侧的发现 ⭐

### 3.1 `events.json` 的作答码标注是错的

文档称 `833–841`「Response 01–09」与 `901–909`「Answer 01–09」
都编码 1–9 的作答值，**实测仅 7.3% 一致**。

用**内部情绪结构**判定（不需要任何外部锚点，也不依赖刺激映射）：

| 期望 | `833–841` | **`901–909`** |
|---|---|---|
| pleasant ↔ happy 应正 | −0.015 | **+0.503** |
| pleasant ↔ tender 应正 | −0.173 | **+0.519** |
| pleasant ↔ afraid 应负 | +0.075 | **−0.584** |
| angry ↔ afraid 应正 | +0.065 | **+0.600** |
| happy ↔ sad 应负 | +0.077 | **−0.299** |
| **应为正的 6 对** | 均值 −0.063（2/6 为正） | **均值 +0.406（6/6 为正）** |
| **应为负的 6 对** | 均值 +0.005（2/6 为负） | **均值 −0.382（6/6 为负）** |

**`901–909` 才是真作答码。** 本报告全部评分结果基于该编码。

⚠️ **任何使用本数据集的人都会踩这个坑** —— 值得单独成文投给数据集页面。

### 3.2 刺激码 → 音频的映射不成立

`events.json` 说「刺激码 301–360，减 300 得 mp3 编号」，
但实测码达 **657**，且 `code − 300` 指向的音频与受试评分毫无关系：

| 检验 | 结果 |
|---|---|
| 受试 8 项自评 × Set1 组均值 8 量表 | 8×8 全部相关绝对值 ≤ 0.16，**无置换对得上** |
| 谱质心 → 受试 energetic | **−0.006**（同一探针对组均值 energy 是 +0.374） |
| 偏移量 −3…+3 扫描 | 全部 ≈ 0 |

**但这些码确实是刺激身份** —— 听到同一码的不同受试评分高度一致
（分半 0.80–0.87）。因此是**编号体系对不上**，不是码无意义。

#### 恢复尝试（`44_recover_stimulus_mapping.py`）：失败

用 8 维情绪剖面 + 匈牙利指派求最优映射，对照「被试内打乱刺激码」的零分布：

| | |
|---|---|
| 观测指派平均剖面相关 | +0.6716 |
| 零分布均值 / 95 分位 | +0.6536 / +0.6808 |
| **p** | **0.194** |
| 与 `code − 300` 重合 | **0.0%** |

**不显著，恢复失败。**

#### 后果

| 可做 | 不可做 |
|---|---|
| 脑电 / 评分的刺激层面信度 | **声学 → 脑电** |
| 评分的内部结构 | **声学 → 受试评分** |
| 脑电 ↔ 评分（同试次） | 与 Soundtracks 组均值的任何联结 |

## 4. 设计约束（必须随结果一起报告）

| | |
|---|---|
| 1,240 试次 / **307 个不同刺激** | 每段音频**中位仅 2 名受试** |
| ≥4 人听过 | 96 段 |
| ≥8 人听过 | **44 段**（分半信度的可用集） |
| ≥16 人听过 | 16 段 |
| 两两受试刺激集重叠 | 中位 **6** 段（最大 40，最小 0） |

README 称「31 名受试听 40 段音乐」，暗示同一批 40 段；
实测每人 39–40 段但**各不相同**，合计 307 段。
这与 §3.2 的编号问题可能同源，**未解决**。

⚠️ 不均衡设计压低了分半信度的精度（仅 44 段可用），
但 ICC 用满全部试次，两者结论一致，故结论不依赖该子集。

## 5. 本结果不能外推到哪里

| 限制 | 说明 |
|---|---|
| **测量量** | 仅测了**试次级带功率变化**。ERP 成分、连接性、时间分辨表征未测 |
| **时长** | 12 s 片段。助眠场景是 30 分钟以上，机制不同 |
| **无 N1** | 播放延迟抖动抹掉了快成分（`step16` §4），毫秒级分析在本数据集不可行 |
| **多重比较** | 26 个特征未做 FDR 校正；beta_central 的 p=0.030 不应视为阳性 |
| **检验力** | 44 段 × ≥8 人的分半，对小 ICC 的检出力有限 |

## 6. 与已撤回结论的关系

`step13` / `step14` 撤回的**具体数字不恢复** —— 那些来自 BIRAFFE2 上
一条从未通过阳性对照的流水线，与本次无关。

但 `step14` 的那句「**我无法建立一条能通过阳性对照的生理流水线**」
**现在不再成立**（`step16`）。

B2 原则（在说「X 预测不了 Y」之前先测 Y 的信度）**在此获得第一个
带完整阳性对照的例证** —— 此前 EDA 的 0.155 因流水线未验证而失效，
本结果可以替代它。
