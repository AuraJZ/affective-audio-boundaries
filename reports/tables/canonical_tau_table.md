# 补充表：个体间斜率 SD（τ）的逐格估计与零分布改正

每格在自己的每人观测数 n 上估计。零分布由**参数化自举**逐格算出：
取该格真实的 x 向量与残差 SD，令 τ=0 生成 y，重估 τ̂，重复 60 次取中位。

改正为方差可加 τ = √(max(τ̂² − τ̂²_null, 0))。

⚠️ 该模型在真值已知的模拟上对 **τ̂** 的平均绝对误差是 3.3%，但那不是本表报的量。

残差**全为正**（+1.3% ~ +4.2%），即模型系统性高估 τ̂、因而系统性**欠改正**。传到本表报的量上：τ 改正值的误差 1.4–14.6%、n\* 的误差最大 +37%，且**在 τ 小处最大** —— 正是生理侧那些格。

`n*` 为按人校准的盈亏平衡观测数；CI 下界改正后为 0 的格，n\* 无上界。
