# 表示对比：CLAP 大幅胜出，但有一个严重混淆

- run_id：`representation_comparison`
- 数据：Emo-Soundscapes 回归集（含混音，n = 1213）
- 表示：Layer A 手工描述符（122 维） vs Layer C CLAP 嵌入（512 维）

---

## 1. 结果

| 表示 × 算法 | Spearman ρ | R² |
|---|---|---|
| **Stacking(A+C)** | **0.8513** | 0.7205 |
| SVR \| A+C | 0.8504 | 0.7189 |
| **RidgeProbe \| C** | **0.8429** | 0.6991 |
| RidgeProbe \| A+C | 0.8425 | 0.6895 |
| SVR \| C | 0.8415 | 0.7048 |
| XGBoost \| A+C | 0.8220 | 0.6750 |
| XGBoost \| C | 0.8124 | 0.6581 |
| RF \| A+C | 0.7880 | 0.6166 |
| RF \| C | 0.7795 | 0.6027 |
| **XGBoost \| A**（手工最佳） | **0.7726** | 0.5978 |
| RF \| A | 0.7486 | 0.5586 |
| SVR \| A | 0.7391 | 0.5301 |
| RidgeProbe \| A | 0.7298 | 0.4919 |

### 1.1 表示比模型更重要

**CLAP 嵌入 + 最简单的线性岭回归（0.8429）
＞ 手工特征 + 调优过的 XGBoost（0.7726）。**

差距 +0.07，而且赢的一方用的是没有任何非线性的线性模型。

**这推翻了笔记 §2.3 引用的论文结论**（「预训练在小样本上不一定赢过经典 ML + 指纹」）——
该结论在分子模态成立，在声音模态不成立。合理：
音频预训练模型见过的数据量与声学多样性，远超分子预训练模型之于化学空间。

### 1.2 精度天花板高于手工特征所示

此前只有手工特征时，最佳 ρ = 0.773，容易误判为「已接近标签噪声上限」。
CLAP 做到 0.843，说明**手工特征还漏掉了可提取的信号**，
瓶颈不（全）在标签质量。

---

## 2. 预训练污染对照：优势为真，但环境声上的数字被夸大一倍 ✅

**混淆**：CLAP 的预训练语料 LAION-Audio-630K 包含 Freesound，
而 Emo-Soundscapes 的 600 段原始录音全部取自 Freesound
—— CLAP 很可能在预训练时见过这些片段本身。

**对照**：在 DEAM（音乐，非 Freesound 来源）上重跑同一对比。

| 语料 | 手工最佳 | CLAP 最佳 | 增益 |
|---|---|---|---|
| Emo-Soundscapes（可能污染） | 0.773 | 0.843 | **+0.070** |
| **DEAM（干净对照）** | 0.736 | 0.773 | **+0.037** |

**结论**：CLAP 的优势在干净数据上依然存在，但**只剩一半**。

Emo-Soundscapes 上的 +0.070 里约有一半来自预训练污染。
**引用本节数字时应以 DEAM 的 +0.037 为准。**

这个对照本身值得记一笔：若不做，会把一个被夸大一倍的数字写进结论。
凡是用公开预训练模型评估公开数据集的研究，
都应先核对**预训练语料与评估语料的来源是否重叠**。

## 2b. 深度嵌入翻不过域之墙 ⭐

```
DEAM → Emo-Soundscapes（音乐 → 环境声）
  Layer A（手工 122 维）:  ρ = +0.132
  Layer C（CLAP 512 维）:  ρ = +0.184
```

CLAP 略好，但**两者都是失败**——组内 ρ ≈ 0.77，跨域仅 0.18。

**这比「能翻墙」更有价值**：域之墙**不是特征设计不足造成的**，
而是**任务的固有属性**。一个在 63 万段音频上预训练的模型同样翻不过去。

推论：若要覆盖多种声音类型，**必须按类型分别建模**，
不能指望「更强的表示」自动解决。

## 3. Stacking：第五次失败，但解释要修正

| | 值 |
|---|---|
| 最佳单模型（RidgeProbe\|C） | 0.8429 |
| Stacking(XGBoost\|A + RidgeProbe\|C) | 0.8513 |
| **增益** | **+0.0084** |

此前四次 stacking 失败，我们的解释是「基模型吃同一份特征、预测高度冗余」。
本次用了**差异最大**的两种表示（手工 122 维 vs 深度 512 维）：

| OOF 预测相关 | 值 |
|---|---|
| Layer A 内部 | 0.864 |
| Layer C 内部 | 0.924 |
| **跨 A/C** | **0.817** |

跨表示相关确实更低（0.817 < 0.864/0.924），**方向与假设一致**，
但差距只有 0.05–0.11，**stacking 增益仍只有 +0.008**。

### 加入 DEAM 对照后的完整图景

| 语料 | 跨表示 OOF 相关 | stacking 增益 |
|---|---|---|
| Emo-Soundscapes | 0.817 | +0.0084 |
| **DEAM** | **0.796** | **+0.0185** |

**跨表示相关越低，stacking 增益越大** —— 「表示冗余」的解释方向被证实。

但效应量很小。准确表述应为：

> **跨表示 stacking 给出一致为正但很小的增益（+0.008 ~ +0.019），
> 远低于原论文在分子上的 +0.037，也远不足以证明其复杂度。**

（此前报告中「stacking 五次失败」的措辞过强，已修正为上述表述。）

### 结论修正

「表示冗余」是**方向正确但不充分**的解释。更准确的说法是：

> **手工描述符与深度嵌入这两种截然不同的表示，
> 对同一批音频给出的预测仍然相关 0.82。
> 说明它们捕捉的是同一个底层信号，剩余方差是各自都拿不到的部分。**

对论文的含义：论文原方法（stacking 提升 0.957 → 0.994）的收益，
很可能来自**分子表示之间真正的互补性**（图 vs 指纹 vs 序列，
描述的是分子的不同侧面）。声学表示则不同——
无论手工还是深度，最终都在描述同一段波形的同一批物理属性。

## 4. 局限

1. **预训练污染未排除**（§2），这是本节最大威胁
2. 只在环境声域做了，音乐域待补
3. CLAP 嵌入**不可解释** —— 512 维无语义。
   它能用来确定精度天花板，但不能用来出规则。
   规则库仍必须建立在手工描述符上。
4. 未测 CLAP 的跨域迁移能力（能否翻过「域之墙」），
   这是比精度更有价值的问题
