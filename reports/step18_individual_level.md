## 0. 我此前问错了问题 🔴

本项目的产品前提**一直是按人校准**。而 `step17` / `45` / `50` 的分析，
名义上叫「被试内」，最后一步都汇总到**跨受试的 Wilcoxon** ——
问的是「这个关系的方向在人群里是否一致」。

**那个问题失败，不蕴含个体问题失败。** 若 A 的 alpha 升高对应放松、
B 的 alpha 升高对应紧张，两人各自都完全可预测，**组平均仍为零**。
而这正是按人校准所要的情形。

因此重做，判据改为：**有多少个体，其脑电能超过该个体自身的零分布？**

---

## 1. 逐个体阳性对照：26/31 通过 ✅

沿用本项目的纪律，把「阳性对照先行」从数据集层面**下沉到个体层面**。

个体级对照取**试次序号**：脑电必然随 session 内时间漂移（阻抗、疲劳、警觉度），
因此每个人的脑电都应能显著预测自己的试次序号。

| | |
|---|---|
| 通过（p<0.05） | **26 / 31** |
| 实测 ρ 均值 | **+0.401** |
| 零分布均值 | −0.222 |

**绝大多数个体的数据本身是好的。** 因此下面的阴性不是「数据坏了」。

（零分布均值为负是 K 折 CV + 相关系数的已知偏倚 —— 训练折均值系统性偏离
被留出的点。**该偏倚被零分布完整吸收**，因此比较必须是「实测 vs 零分布」，
而不是「实测 vs 0」。`45` 初版没做这个比较，得出过无效结论。）

## 2. 主结果：个体层面精确落在随机水平

156 维特征 → 折内 PCA(8) → RidgeCV，5 折 CV，
**每个「个体 × 维度」带 200 次该个体自身的标签置换**。

| | 观测 | 随机期望 |
|---|---|---|
| p<0.05 的「个体 × 维度」 | **13** / 248 | 12.4 |
| 至少一个维度显著的个体 | **10** / 31 | 10.4 |
| BH-FDR q<0.05 | **0** | — |

二项检验 **p = 0.47**。

最强的几个（sub-17 energetic ρ=+0.470、sub-18 pleasant ρ=+0.423）单看很像结果，
但 248 次检验中出现若干 ρ≈0.4 正是随机应有的样子。
**这正是零分布存在的理由。**

### 唯一略高于期望的一项，已被 ICA 排除 ⚠️

`afraid` 维度 **6/31** 个体显著，期望 1.55。
单独看二项 p≈0.009；校正 8 个维度后 p≈0.07。

**ICA 后掉到 4/31**（§4b）—— 若为真效应，去除眼电应使其增强而非减弱
（对照效应正是如此变化的）。**判为噪声，不计为发现。**

## 3. BIRAFFE2 重查：撤回依据升级 ⭐

`step14` 的撤回依据同样是**组水平**的（习惯化 ρ 均值 +0.113）。
但「均值为正」与「多数个体为正」不是一回事 ——
若一部分受试设备正常、另一部分电极脱落，组平均会被坏数据拖偏，
**而好的那部分仍可用**。BIRAFFE2 的数据集论文本身记录了大量设备错误，
这个先验是存在的。

逐个体重跑两项对照（94 名可分析受试，每人 500 次自身置换）：

| 逐个体阳性对照 | 通过 | 随机期望 |
|---|---|---|
| 习惯化（ρ<0 且 p<0.05） | 8 / 94 | 4.7 |
| 刺激锁时（p<0.05） | 4 / 94 | 4.7 |
| **两项都过** | **0 / 94** | 0.24 |

**决定性的一个数：只有 35% 的个体习惯化 ρ 为负**（应远超 50%）。

方向反了**不是**少数坏数据拖偏组平均，而是**多数个体本身方向就是反的**。
「存在可用子集」这一假设被排除。

> `step14` 的全撤维持原样，但依据从「组平均失败」升级为
> 「94 个个体逐一验证，无一通过」。

## 4. ICA 去眼电：补上一个属于我的缺口

此前的带功率（`39`）与相干（`46`）**都没有做伪迹去除**。
眨眼与肌电混在 13 秒响应窗里会抬高噪声、**压低所有效应量** ——
方向上不利于本项目的阴性结论。不补上，「我们测不到」可被一句
「你没清伪迹」驳回。

`52_ica_cleaned_features.py`：ICA（15 成分）+ FP1/FP2 作 EOG 代理，
**其余参数与 `39`/`46` 完全一致** —— 唯一差别是 ICA，否则无法归因。

| | |
|---|---|
| 每个 run 剔除成分数 | 中位 1，均值 1.2，最多 2 |
| 一个都没剔的 run | 5 / 124 |

### 4b. ICA 同时充当了灵敏度的操纵检查 ⭐

| | ICA 前 | ICA 后 |
|---|---|---|
| **阳性对照通过** | 26 / 31 | **29 / 31** |
| **阳性对照 ρ 均值** | +0.401 | **+0.573** |
| 状态解码 p<0.05 | 13 / 248 | **9 / 248**（期望 12.4） |
| 二项检验 p | 0.47 | **0.88** |
| `afraid` 维度显著个体 | 6 / 31 | **4 / 31** |

**同一个预处理步骤，使已知效应的检出明显上升，却使目标效应进一步下降。**

这是阴性结论能取得的最强形式：**「信噪比不够」这个解释被直接排除** ——
我证明了把信噪比提上去之后，已知效应变强了（ρ +0.401 → +0.573），
而目标效应没有。ICA 在此不是清洗步骤，而是**操纵检查**。

§2 中标记为「值得复查」的 `afraid`（6/31）在 ICA 后掉到 4/31，
符合其本为噪声。**该项不再列为待复查。**

## 6. 本结果的适用范围 —— 必须与结论同时报告 ⚠️

| 限制 | 数值 | 为什么要紧 |
|---|---|---|
| **每人试次数** | ~30 | 校准模型的样本量。消费级设备一夜可采集数百段 |
| **暴露时长** | 12 s | 助眠场景是 30 分钟以上，机制不同 |
| **重复次数** | 单次 | 无个体内重复，无法分离状态与特质 |
| **测量** | 头皮 EEG 带功率/相干 | 未测 HRV、呼吸、体动等消费级设备的主力信号 |
| **无 N1** | 播放延迟抖动 | 毫秒级分析在本数据集不可行 |

> **正确的表述**：在「~30 个试次、12 秒片段、单次暴露、头皮 EEG」这一组合下，
> 个体层面的脑电→自评关系不可检出。
>
> **而非**：「按人校准不可行」。

这个区分对产品是实质性的：上表里的每一项限制，**你们的硬件恰好都能突破** ——
整夜采集意味着试次数高两个数量级，长时暴露意味着效应机制不同，
跨夜重复意味着能做个体内校准。**学术界拿得到 DEAP，但没有能整夜采集的消费级设备。**

## 7. 方法学教训（本轮新增）

**「被试内分析」与「个体层面判据」不是一回事。**

`45`/`50` 每一步都在被试内做，但最后一步的**判据**是跨受试的 ——
只要判据在组水平，方向因人而异的关系就会被抵消掉。

判断标准很简单：**零分布是谁的？** 若零分布来自「跨受试的统计量」，
问的就是群体问题；只有零分布来自「该个体自身的标签置换」，
问的才是个体问题。

这与 B1/B2/B6 是同一族错误的第四个实例：**统计量报出来了，
但它的参照分布回答的是另一个问题。**
