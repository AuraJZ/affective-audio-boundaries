% Legends run long (up to ~570 words). At \small with 1.5 line spacing a
% caption can exceed the text block, which silently truncates it and overprints
% the page number. Captions are therefore set single-spaced and one size down,
% and each figure is given a page of its own.
\captionsetup{font={footnotesize,singlespacing},labelfont=bf,
              justification=justified,singlelinecheck=false,
              skip=6pt}

% 🔴 Figures are NOT floats. This is the fix for a defect that was losing text.
%
% They used to be \begin{figure}[p]. A float is one unbreakable box, so when the
% image and its legend together exceed the page, LaTeX does not reflow and does
% not shrink -- it prints past the bottom margin, over the page number, and
% clips the remainder. Five of the eight main figures were doing this, the worst
% by 341 pt (120 mm), and the end of those legends never reached the PDF.
% It is a silent failure: the structure checker cannot see it, and the only
% warning is "Float too large for page by ..." buried in the log.
%
% Shrinking the images cannot fix it. Fig. 1 would have to come down to roughly
% 80 mm for its legend to fit beside it, which puts the panel type below the
% 6 pt floor the figure contract sets.
%
% As ordinary (non-floating) content with \captionof, a legend that outruns its
% page simply continues on the next one. Nothing is clipped. The cost is that a
% few figures now span two pages, which is the correct trade.
\usepackage{capt-of}

%
% {\centering ... \par} rather than the center environment: center adds its own
% vertical skips and closes with an empty paragraph, which lineno then numbers,
% leaving a stray line number floating under the image.
\newcommand{\msfigure}[3]{%
  \clearpage
  \nolinenumbers
  {\centering\includegraphics[width=\textwidth]{#1}\par}%
  \linenumbers
  \captionof{figure}{#3}\label{#2}%
}
